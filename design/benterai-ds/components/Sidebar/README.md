# Sidebar

Desktop app navigation on the corporate navy `sidebar` surface: reversed wordmark, primary New chat, five destinations (AI conversations / Knowledge / Create files / Organization / Settings), Recent chats with search grouped Pinned / Today / Previous 7 days, and the user box with Sign out. Menu labels follow the separate menu-language setting (English default). A destination without permission stays visible, muted, with a lock and a tooltip — clicking does nothing. On mobile the whole sidebar opens as a drawer from the top-bar menu button.
