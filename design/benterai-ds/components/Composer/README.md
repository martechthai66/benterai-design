# Composer

Where every chat starts. `hero` size (3 lines) on the new-chat welcome, `docked` at the bottom of a thread. Anatomy: attachment chips > textarea (Enter sends, Shift+Enter new line, IME-safe) > bar [`+` menu · web-search chip when on · spacer · ModelPicker · Send/Stop] > Knowledge row [ไม่ใช้เอกสาร / ทุกเอกสารที่พร้อมใช้ / เลือก 1 ฉบับ + document select] > data-handling note. Send is disabled while empty or while an attachment is not ready; while streaming it becomes Stop.
